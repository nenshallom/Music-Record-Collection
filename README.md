# Record Collection Manager

A simple frontend project to manage a collection of music records.
Users can add, search, sort, and delete records — fully interactive using vanilla JavaScript.

## Features
- Add new records (Title, Artist, Year, Genre)
- Search records live while typing
- Sort records by Title or Year (ascending/descending)
- Delete records with confirmation prompt
- Responsive user feedback ("No records found" message)

## Technologies Used
- HTML5
- CSS3
- JavaScript (ES6+)

## How to Use
1. Clone or download the project files.
2. Open `index.html` in your browser.
3. Add, search, sort, and delete records!

## Future Improvements
- Connect to a backend server to permanently save records
- Add user authentication (login/signup)
- Improve UI with TailwindCSS/React.js
